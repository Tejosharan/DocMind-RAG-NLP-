# DocMind-RAG-NLP

RAG pipeline — animated stages: Upload → Chunking → Embedding → Vector Store → Retrieval → Generation
Live Q&A chat — ask questions, it retrieves top-3 relevant chunks with cosine similarity scores and generates grounded answers with source citations
NLP Analysis tab — Named Entity Recognition (persons, orgs, locations, technologies), Sentiment Analysis with bar charts, Keyword Extraction, Text Summarization
Vector Store tab — shows all document chunks with similarity scores highlighted after retrieval
File upload — drag and drop any .txt file and it gets chunked and indexed live

Keywords HR will see: RAG, Vector Search, Embeddings, NLP, NER, Sentiment Analysis, Chunking, Cosine Similarity
